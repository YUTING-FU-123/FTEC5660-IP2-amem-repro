What the system does

A-Mem (NeurIPS 2025) replaces flat memory with Zettelkasten notes.

  • Note construction — keywords, tags, context for every utterance
  • Link generation — connect to nearest notes
  • Memory evolution — rewrite neighbours' context and tags
  • Retrieval — top-k notes → answer

Multi-step, tool-calling, self-modifying → an agentic system, not a single prompt.

Official eval repo: github.com/WujiangXu/A-mem

Why the gaps are there

  • Temporal −8.7: date normalisation, not retrieval — gold “19 January, 2023”, model “Yesterday, 20 January 2023”.
  • Open-domain +12: we feed ~14.2k tokens of context per question, the paper reports 2,520.
  • Context cost does not reproduce: 5.6× the reported number at the repo's default k.
  • Adversarial not comparable: harness default scores against “Not mentioned”, the paper scored against the adversarial answer.

Our modification: remove memory evolution

Δ F1 = +0.02 · prompt tokens −37% · context per question −45%

Paper reports the opposite: multi-hop 27.02 → 21.35 without ME.

7 / 8

Lessons

  • pitfall The harness caches memories by sample index — two subset files silently share sample 0. Tag the cache by dataset.
  • cost One conversation is already ~1,700 LLM calls; measure tokens before choosing a scale.
  • model swap Disable thinking and raise max_tokens, or 20% of outputs come back empty.
  • finding Accuracy reproduces within ~1 point; efficiency and ablation claims do not.
